# Security

Report a vulnerability through [GitHub private vulnerability reporting](../../security/advisories/new) on this repository. Please don't open a public issue for one.

Most useful reports: a way out of the player sandbox, a way for a website to drive the local server, a way past the download checks, or a file that crashes the library page rather than the emulator.

See the Security section of the README for what retro-zip enforces and what it can't promise.
